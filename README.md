# Java Noughts and Crosses (Tic-Tac-Toe)

A scalable, dynamic Noughts and Crosses game built using JavaFX, and Maven. 

## Features
* **Dynamic Grid Sizing:** Players can choose a custom board size between 2x2 and 9x9.
* **Global Score Tracking:** The application tracks player names and player scores using Java properties.
* **Event Driven Programming:** Waits in the background for user inputs.

## Technologies Used
* Java
* JavaFX
* Maven

## How to Run Locally
1. Clone the repository: `git clone https://github.com/Nickoloke/NoughtsandCrosses.git`
2. Navigate to the project directory: `cd NoughtsandCrosses`
3. Build and run using Maven:
   ```bash
   mvn clean javafx:run
